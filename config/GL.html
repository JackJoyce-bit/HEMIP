Génie Logiciel
Stratégie de l'entreprise
Développer le domaine du Génie Logiciel vise à aligner le capital humain avec les innovations technologiques
Objectifs de formation
  • Maîtriser les architectures modernes : Former les équipes sur le cloud (AWS, Azure, GCP) et la conteneurisation (Docker, Kubernetes).
  • Adopter le code propre (Clean Code) : Standardiser les revues de code, le refactoring et les tests automatisés (TDD/BDD).
  • Intégrer l'IA générative : Apprendre à utiliser les assistants de code (GitHub Copilot) de manière sécurisée et efficace.
Évolution

La formation permet aux ingénieurs d'évoluer selon trois dimensions majeures du génie logiciel.

  • Évolution des rôles : Passage de développeur de code (Full-Stack/Back-End) à concepteur de systèmes ou facilitateurs d'équipes (Tech Lead).
  • Le Green IT : Transition des pratiques de codage traditionnelles vers l'éco-conception logicielle (optimisation des ressources et de l'énergie).
  • Expertise sécurité : Mutation du rôle développeur vers celui de contributeur actif à la sécurité du code (Shift Left Security).
